# 叙脉使用说明

这是一份给作者的本地开发版说明。叙脉的唯一标语是“新一代写作体验”，产品提供两条路径：你可以自己写，也可以让 AI 辅助推进，但最终作品正文始终属于你。

## 1. 安装、启动与停止

在已经安装 Python、`uv` 和 Node.js 的电脑上：

```bash
git clone https://github.com/Reen-Ai-H/novelagent-xumai.git
cd novelagent-xumai
uv venv .venv
uv pip install --python .venv/bin/python -r requirements.txt
cp .env.example .env
.venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

打开 <http://127.0.0.1:8000>。回到启动服务的终端按 `Ctrl-C` 停止。端口被占用时可以换一个本地端口，并用对应地址访问。

这是本地 JSON 持久化的开发版，不是公网云服务。刷新、离开页面和重新登录可以恢复同一服务端数据目录中的作品；这不等于跨服务器云同步。

## 2. 登录与书架

输入邮箱即可完成本地开发登录。账户和会话由服务端保存，浏览器刷新或退出重登后仍能回到自己的书架。手机号和微信入口目前只是“即将开放”，不会误报登录成功。

书架支持搜索、查看章节数、字数、进度、最近编辑、积分和后台状态，也能新建作品。AI 作品显示钴蓝色“AI 辅助写作”标识，独立作品不显示这个标识。开发演示的创作积分预算和已用均为 0，不代表未来正式计费规则。

## 3. 独立创作

选择“独立创作”后可以：

1. 从空白开始，或上传 TXT、MD、DOCX。
2. 先查看导入预览：标题、识别出的章节、字数和无法识别片段；确认后才写入正式正文。空文件、无有效章节、格式或大小不合要求会保留输入并说明原因。
3. 在安静的三栏编辑器中编辑正文。左侧是作品与章节目录，中间是正文，右侧可以收起故事档案摘要。独立编辑器不会提供 AI 续写、改写或代写按钮。
4. 正文会先短暂缓冲，再自动保存到服务端；页面会显示保存中、已保存、失败重试或修订冲突。内部导航会等待保存成功，避免快速离开丢稿。
5. 点击“完成本章”后，系统在保存成功的基础上创建后台分析任务。你可以离开页面；任务恢复后会生成确定性分析或模型分析、章节快照、人物状态、剧情线、伏笔、疑问点和站内通知。

故事档案是一整页工作区，默认显示最新状态；四个纵向区块分别是人物、剧情线、伏笔、疑问点，每条内容带来源章节。任意历史章节快照只读，回到最新状态后才能继续编辑。未配置图片服务时，角色使用非具象角色牌并明确提示；角色试绘必须由你选择画风、确认预计积分后按需触发，不会自动生成全员人像。

### 作品拆解

独立作品完成至少一章后，打开正文侧栏的“作品拆解”。页面只读取当前正式正文，提供作品概览、0–100% 节奏时间线、逐章结构表和最小证据回链；每条结论都标明来源章节。结果会在服务端后台排队，离开或刷新页面不会中断。

页面状态的含义很简单：没有正文时是“等待正文”，任务执行中是“已排队/拆解中”，完成后是“已完成”；失败可“重试拆解”，正文变化后会显示“结果已过期”，有未确认作者修改时会先提示“需要确认”。历史结果只读，证据来源变化时不会强行跳到当前同编号章节。

## 4. 旧章修改与恢复

修改旧章或既有 AI 正文时，所有改动进入同一批“待确认修改”。正文逐字保存，但不会立刻替换正式分析。点击“确认全部修改”后，系统展示修改章节、增删字符、影响范围和建议，你最后选择：

- “忽略轻微措辞并继续”：提交当前正文，保留现有档案，并记录未重建。
- “根据当前全文重建档案”：创建同一作品的新当前稿本，从全文重建档案；旧正文和旧分析进入 30 天可恢复期。

历史正文可以预览和恢复。恢复会创建新的当前稿本，不改写历史记录，也不会产生平行正文。若提示 `author_revision_conflict`，说明后台 AI 事务检测到作者新修订；保留作者正文，按提示重试，不要直接编辑 JSON。

## 5. AI 辅助写作

选择“AI 辅助写作”后进入创作室。你只和“主编”对话；剧情、人物、世界观、节奏等专业角色以后台状态显示，不会变成多个聊天窗口。对话逐步补全九项蓝图：核心命题、主冲突、主角及动机、关键人物关系、世界规则、预期体量、结局方向、分卷/阶段大纲等。字段也可以直接编辑，未齐时页面会说明缺少什么。

主动点击“确认蓝图并开始创作”后进入导演台。导演台支持：

- “全自动继续”：后台连续轮转。
- “关键节点暂停”：在节点等待你做决定。
- 暂停、继续、离开页面后恢复、失败重试，以及完成后进入正文或故事档案。

关键节点始终恰好有三个互斥选择，其中一个是“把决定交给角色”。选中的路线成为唯一正式路线，不保留可切换的平行正文。设置里的“提前展示选择后果”默认关闭；打开后只显示不确定的可能后果，关闭时不会通过接口或页面泄露具体剧透。

AI 正文完成后可以进入普通正文编辑器。手改仍使用上面的待确认修改合同，不在编辑器里提供 AI 续写聊天。无 Key 时界面标注“演示推演”，不消耗创作积分；有有效配置时显示模型已连接·开发测试，仍不结算正式积分。供应商失败会进入可重试失败态，不静默换成演示模板。

## 6. 数据、备份与隐私

服务端会使用以下本地目录保存账户、作品、档案、事务和安全模型元数据：`.novel_accounts`、`.novel_ai`、`.novel_independent`、`.novel_projects`、`.novel_memory`、`.novel_transactions`。不要直接编辑其中的 JSON，也不要把它们提交到 Git。

备份前先停止服务，复制相关目录到受保护位置，并保留原目录副本。恢复前再次停止服务，先备份当前目录，再放回完整备份。不要把 `.env`、账户或正文发给他人。故事人物私有记忆只用于服务端单人物推演，不会返回浏览器。

## 7. 配置模型

复制 `.env.example` 为 `.env` 后，按需填写变量；模板没有任何真实值。可使用 OpenAI-compatible 提供方，例如：

```dotenv
OPENAI_API_KEY=
OPENAI_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
LLM_TEMPERATURE=0.7
```

也兼容 `DASHSCOPE_API_KEY`、`DASHSCOPE_BASE_URL`、`DASHSCOPE_MODEL`，以及 `LLM_BASE_URL`、`OPENAI_MODEL`。不要打印、复制或提交 Key。无 Key 时可使用完整的确定性演示；有 Key 时模型坏 JSON、超时、401、429 或正文校验失败会明确显示原因并允许重试。

## 8. 常见问题

**端口被占用**：换用 `--port 8001`，并访问新的本地地址。

**依赖安装失败**：确认使用项目 `.venv/bin/python`，重新执行 requirements 安装；不要删除作品数据来排查依赖。

**导入后没有章节**：检查 TXT/MD/DOCX 是否为空、编码是否可读、是否包含有效正文；导入预览会告诉你失败原因。

**保存冲突或 `author_revision_conflict`**：先等待页面保存状态明确，再按提示重试。作者新 revision 永远优先，后台不会覆盖正文。

**模型提示 `provider_bad_json`**：结构化人物/审校/档案阶段需要严格 JSON；检查模型配置和供应商响应，重试不会把错误结果写入档案。正文阶段使用独立纯文本协议。

**通知没有跳转**：先刷新并确认仍登录同一账户；通知只允许跳转到应用内目标。服务端失败时弹层不会假装已读或跳走。

**浏览器显示异常**：使用现代浏览器，检查页面宽度和控制台错误；开发版不承诺公网反向代理、跨域部署或云端同步。

## 9. 当前限制

这是功能审计通过后的开发版，不是生产部署。阶段 27 独立审计 P0/P1/P2/P3 均为 0；真实 DeepSeek 连续三章链路已经验证。文学质量阶段 23B 结论为 C。项目外离线质量门研究 Q2 已验证（脱敏黄金集宏 F1=1.000、semantic-needed 覆盖率 1.000、14 项测试通过、外部请求/Token/费用为 0），但真实生成质量增益及产品集成仍 pending，Q3 本阶段不执行。

目前没有正式支付、积分充值、管理员账户、多人协作、分享发布、生产账户或公网安全承诺。开发测试显示的 0 积分是安全开发合同，不等于未来正式价格。备份前停服务；永远不要提交 `.env` 和 `.novel_*` 数据。

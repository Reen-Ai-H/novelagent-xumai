## 任务

### 0. 基线与进度

- 按 `../AGENT_WORKFLOW.md` 创建根目录 `PROGRESS.md` 和 `BLOCKED.md`。
- 用 uv 创建 `.venv`、安装 `requirements.txt`，运行 `.venv/bin/python -m unittest discover -s tests -v`。
- 测试数不是 14 或基线失败时保留原始证据，只继续不受影响部分。
- 启动 FastAPI，实测首页和现有 API 后再改代码。

### 1. 应用壳与七页

实现营销首页、邮箱登录、书架/新建作品、独立编辑器、故事档案、AI 创作室、AI 导演台。关键文案使用真实 DOM；导航、返回、空态、错误、加载、禁用状态完整。首页和登录有克制的故事线动效并支持 `prefers-reduced-motion`；内部工作区保持安静。

### 2. 账户、书架与模式

邮箱会话可恢复；作品卡显示章节、字数、进度、最近编辑、创作积分和后台任务状态。新建必须选择“独立创作”或“AI 辅助写作”；AI 作品有钴蓝标。手机号/微信只显示“即将开放”。

### 3. 独立创作闭环

支持首次全文导入、以后逐章追加和网页自动保存；完成本章后在后台更新人物、剧情线、伏笔、疑问点和快照，允许离页并通知。故事档案默认最新，可切任意章节。默认使用非具象角色牌；角色试绘只有选画风、确认积分后按需触发。

### 4. 集中修改与版本恢复

旧章编辑只保存待确认稿；“确认全部修改”展示范围与建议，让作者选择忽略轻改或全文重建。重建必须在同一作品创建新稿本版本，旧分析立即替换，旧正文保留 30 天可恢复。两种作品模式共用逻辑，不产生平行正文。

### 5. AI 辅助闭环

创作室只让作者与主编对话，后台展示剧情/人物/世界观/节奏状态，右侧蓝图持续保存并可确认。导演台可推进角色推演→正文生成→审查→档案更新，支持暂停、后台继续和恢复。角色私有记忆互不共享，只共享世界观与必要事实；关键节点三选一后继续唯一正文。可能后果默认隐藏。

### 6. 测试与视觉证据

复用现有可靠 API；新增模型、路由和持久化行为必须有无 Key 确定性测试。不得用纯前端假数据冒充持久化。提交 7 张 1440×900 实现截图，以及独立、AI 两条路径的连续浏览器证据。

## 禁止的达标方式

- skip/todo、删旧测试、放宽断言、吞异常、`|| true`。
- 自动化测试真实调用付费模型。
- PNG 原型作为页面背景冒充实现。
- 独立编辑器加入 AI 续写或改写。
- 修改一个字立即创建版本或重建全文。
- 同时保存多条平行正文。

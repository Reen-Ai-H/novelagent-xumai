# 叙脉 A 版设计系统

状态：首版现役视觉方向

## 1. 方向结论

首版采用 A“故事档案室”。选择原因：产品介绍首页表现最好，同时在文学感、信息密度、长期工作区可用性和品牌辨识度之间最均衡。

## 2. 视觉语言

### 色彩

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 霜纸 | `#F4F7FA` | 页面大背景 |
| 纯纸 | `#FFFFFF` | 正文与主卡片 |
| 墨蓝 | `#111827` | 主文字、深色导航 |
| AI 钴蓝 | `#2F5BFF` | AI 模式、主操作、运行状态 |
| 朱批 | `#D45745` | 编辑批注、重要疑问，不用于普通错误轰炸 |
| 档案灰 | `#A8B3C3` | 分隔、次级元数据 |

允许从这些色值推导浅色背景和交互态，但不得引入另一套主色。

### 字体角色

- 界面：MiSans、HarmonyOS Sans 或可用的现代中文无衬线回退。
- 正文与少量关键标题：思源宋体/Noto Serif SC 类中文宋体。
- 章节号、字数、时间和运行状态：IBM Plex Mono 类等宽字体。
- 不因字体未安装阻塞页面，必须提供合理系统回退。

### 形态

- 精密而舒展，像现代档案馆与专业写作软件的结合。
- 左侧导航来源于书脊、章节索引和档案签，不做通用 SaaS 图标栏。
- 角色默认图是非具象角色牌：文字、纹样、色块或活字，不出现随机 AI 人像。
- 卡片边界轻、留白足，避免满屏细线、密集网格和无意义图表。
- 圆角克制；不用玻璃拟态、渐变霓虹、3D 球体、机器人头像和粒子宇宙。

## 3. 签名元素：故事脉络线

一条细而清晰的故事线连接手稿、人物、剧情和章节快照。它必须编码真实关系：

- 首页：从手稿抽出并分为“独立创作 / AI 辅助写作”。
- 登录：从产品叙事收束到邮箱输入区。
- 书架：可作为作品进度或模式的细节，不抢卡片信息。
- 故事档案：承担时间、来源章节和状态回溯。
- 蓝图：把对话中的关键决定连接到蓝图字段。
- 导演台：连接共享世界观与分离的角色私有记忆。

不要把它退化成装饰性曲线或到处重复的分隔线。

## 4. 页面要求

### 产品首页

- 顶栏：叙脉、功能、作品示例、登录、开始试用。
- 只出现小标语“新一代写作体验”。
- 主标题“让长篇故事记得自己”。
- 首屏包含真实产品组合，不用设备外框。

### 登录页

- 左侧延续手稿、角色索引和脉络线，右侧是可信邮箱表单。
- 不做孤立居中的通用登录卡。

### 书架与新建作品

- 左侧书脊导航，顶部欢迎、搜索、创作积分。
- 作品卡重点是进度与继续写作；AI 蓝条清晰但不过度宣传。
- 两种新建模式用大选择面板说明差异。

### 独立编辑器

- 三栏：章节目录、宽阔正文、可收起的轻量档案。
- 主操作只有保存/完成本章等写作动作，不出现 AI 写作工具。
- 正文区是视觉中心，右栏不能像监控仪表盘。

### 故事档案

- 章节快照控制位于顶部。
- 人物、剧情线、伏笔、疑问点围绕可回溯时间轴组织。
- 疑问点语气温和，朱批色只作提示。

### AI 创作室

- 中央是主编对话，右侧是实时蓝图。
- 后台专业角色仅作为状态，不堆四个聊天机器人。

### AI 导演台

- 显示章节运行阶段、预算、暂停、正文预览、角色私有记忆和关键节点。
- 不出现平行正文分支树。

## 5. 动效

### 首页与登录

- 可以使用 2.5D SVG/DOM：滚动驱动故事线延展、档案卡轻微错层、角色牌进入索引位置、登录线条收束。
- 动效服务理解页面关系，不做长时间自动炫技。
- 页面首次可交互时间不应依赖动画结束。

### 内部工作区

- 只保留状态切换、面板展开、保存反馈和轻量过渡。
- 正文输入、章节切换和关键选择不使用夸张位移。

### 无障碍

- 遵守 `prefers-reduced-motion`，关闭非必要运动。
- 键盘焦点可见；颜色不是状态唯一载体。
- 正文与关键操作满足清晰对比度，不能为了“纸感”降低可读性。

## 6. 响应式与实现

- 首要设计画布：1440×900。
- 1024px 以上保持完整工作流；侧栏可以收窄或折叠。
- 更窄屏幕首版保证可读、可保存和不丢操作，不要求复刻桌面三栏。
- UI 文案、图标、线条和角色牌优先用 HTML/CSS/SVG 实现；PNG 原型不得作为页面背景冒充实现。

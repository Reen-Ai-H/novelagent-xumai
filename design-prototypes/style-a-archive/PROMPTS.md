# 版本 A · 故事档案室生成记录

生成方式：Codex 内置 `image_gen`（新图生成，每个页面单独调用一次）。

所有提示词共同使用以下基础约束：桌面 Web 产品高保真 UI 原型；16:10、约 1440×900；页面本身正视图；不是设备样机或概念艺术；品牌为“叙脉”，唯一小标语为“新一代写作体验”；霜纸 `#F4F7FA`、墨蓝 `#111827`、AI 钴蓝 `#2F5BFF`、朱批 `#D45745`、档案灰 `#A8B3C3`、纯纸 `#FFFFFF`；界面使用现代中文无衬线，正文与关键标题使用克制宋体，章节与状态使用等宽字；避免奶油色、通用 Bento、玻璃拟态、机器人、3D 球体、粒子宇宙、设备外框、水印和无关英文；主要中文标签要求准确。

## 01-landing.png

生成“叙脉”产品介绍首页。顶栏含“功能 / 作品示例 / 登录 / 开始试用”；主区仅有小标语“新一代写作体验”、标题“让长篇故事记得自己”、说明“独立创作，或让 AI 辅助写完整部长篇。人物、剧情线与章节记忆始终清晰。”、按钮“开始试用 / 看看如何工作”。首屏直接展示真实手稿、非具象人物档案、剧情线和 AI 导演台组合。一条钴蓝故事线从手稿抽出，经过人物与剧情档案，最终分成“独立创作 / AI 辅助写作”两条路径；暗示 2.5D 滚动动效。

## 02-login.png

生成邮箱登录页。非居中通用卡片：左侧三分之二是手稿、角色索引卡和逐渐收束的故事线；右侧是安静登录表单。故事线最终成为邮箱输入框的焦点边框。文案：“叙脉 / 新一代写作体验 / 继续你的故事 / 邮箱 / name@example.com / 使用邮箱继续 / 手机号登录 / 微信登录 / 即将开放 / 首次登录将自动创建账户”。无密码、二维码和额外注册表。

## 03-library-new-project.png

生成登录后的书架首页，并打开“新建作品”选择层。左侧书脊导航，顶部欢迎、搜索和“创作积分 8,420”。三本作品卡：“雾港来信”100 章、326,480 字、72%；“第七码头”38 章、112,600 字、生成中，使用钴蓝顶条和“AI 辅助写作”；“长夜航线”24 章、68,210 字。选择层包含“独立创作—上传旧稿或从空白章节开始”和“AI 辅助写作—与主编补全蓝图，再由导演台持续创作”。

## 04-independent-editor.png

生成不含 AI 正文生成的独立创作编辑器。三栏：左侧书脊导航和第 98–102 章目录，当前“第 101 章 暗潮”；中央宽阔中文正文纸面；右侧可收起故事档案，只含“本章变化 / 人物状态 / 剧情线 / 疑问点”。顶部仅显示“已保存 / 本章 2,846 字 / 完成本章”。不得出现 AI 续写、改写、聊天、评分和仪表盘。

## 05-story-archive.png

生成 100 章长篇的“故事档案”。顶部为“当前状态 · 截至第 100 章”和“查看第 20 章快照”的章节快照轨道；下方围绕一条连续故事谱系组织“人物 / 剧情线 / 伏笔 / 疑问点”。角色使用非具象角色牌，状态变化带来源章节；剧情线包括“失踪档案 / 旧港封锁 / 钟楼回声”和“推进中 / 已回收 / 暂未推进”。疑问点使用温和原句：“林舟本章开始畏惧高处，但第 3 章曾独自攀塔——这是人物变化，还是需要回看？”

## 06-ai-blueprint-chat.png

## 07-ai-director.png

生成运行中的“AI 导演台”。左侧“导演台 / 编辑正文 / 故事档案 / 作品设置”；顶部“正在创作第 38 章 / 角色推演 / 正文生成 / 审查 / 创作积分 8,420 / 本次预算 2,000 / 暂停创作”。显示最新章节预览、四个分离的非具象角色智能体及各自“私有记忆”，下方由“共享世界观”公共基线连接但不合并记忆。右侧“关键节点—林渡准备进入封锁区”，三个选项：“相信顾遥的警告，暂时撤退 / 隐瞒发现，独自进入 / 把决定交给林渡”，并显示“可能后果已隐藏”。不出现平行正文分支树。

## 已知限制

图像模型在极小字号的长段中文中可能产生个别错字；版式、层级、关键按钮和核心标签已作为本轮比较重点。进入代码实现时所有文字将使用真实 DOM 文本，不受位图文字限制。

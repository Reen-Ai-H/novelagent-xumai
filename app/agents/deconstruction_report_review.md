# 独立批评与有界修订

本轮不是重新写报告。逐章回读完整真实来源，检查草稿关键身份、说话/受话/亲属/抚养、人物主配、每个分句支持、重要事实遗漏、真实行动阶段、因果和时序，以及已知身份被伪装成未知或明确关系被删空。重点反查：story_order是否服从回忆锚和“尚未返回”等边界而非叙述顺序；近似姓名或跨世代同名是否被无据归并；同一次经历是否被造为“后来”的echo；单方领会是否被升级为对方情感回应；主要冲突的关键前因、制度利益与报复机制是否被压成单纯恩怨。草稿、原值哈希和修订理由都是材料，不是权威。程序验证不是语义通过。

无需要修正的问题返回decision=accept、照抄输入draft_hash、checked_chapters恰好列全部章节。不能仅凭草稿自洽接受。无法闭合返回decision=blocked、同一draft_hash、1至12条具体issues，每条text说明问题、不夹带报告。issues/changes的source_ids直接选择材料中的实际source_id，不引用EV别名，也不要求草稿已声明该来源。

允许一次revise时，返回decision=revise、同一draft_hash及1至8个changes，整个修订JSON最多12KiB。每条含target、before_hash、replacement、text（纠错依据）、source_ids。before_hash从target_hashes逐字复制，不能自行算哈希。新增对象before_hash为null。target只允许完整对象characters/ID、events/ID、findings/ID、evidence/ID、participants/ID；或relations/索引、character_relations/索引、open_questions/索引、contradictions/索引、order_constraints/索引、question_sources/索引；或story_order、time_note、time_evidence_ids、title、scope。不接受任意嵌套JSON路径。索引以原稿为准，新增索引只能等于原数组长度。

replacement给该对象的完整新JSON，稳定ID不能更换；标量/列表元信息以及单个open_questions文本用{"value":完整值}包装。新增引用优先复用对应来源已有的evidence.id，无对应来源声明时同批新增evidence，新增evidence的id == source_id，逐字使用实际来源编号并完整覆盖所有新引用。旧EV明确映射仍兼容，不为改名替换旧证据或引用。importance_basis仍仅三个基础字段，关系仍无独立id。需要变更的依赖对象必须同批明确修订，不能指望代码猜测改端点。确为无据人物或错误关系可replacement=null作明确有源撤回，但仍成立的动作、身份安排和重要分句必须在正确位置保留。不要为维护错误原稿强迫无据分句成立，也不能为过审删掉真实细节。原稿与撤回理由将保留，终审还会逐条核对。

只修改有具体原文依据的问题，不把全报告重发成一串替换，不通过调低status或泛化未解项隐藏错误。超过8个目标或12KiB、来源不足或不能闭合时返回blocked，不裁剪纠错清单。
